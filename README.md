# TP Organización Empresarial – Gestión Colaborativa con Git, GitHub y Jira

## Descripción del Proyecto

Este proyecto fue desarrollado para la materia Organización Empresarial de la Tecnicatura Universitaria en Programación (UTN).

El objetivo principal consiste en aplicar conceptos de gestión organizacional, trabajo colaborativo, trazabilidad y control de versiones utilizando herramientas profesionales como Git, GitHub, Jira y Google Colab.

El escenario seleccionado corresponde al análisis de ventas de una pequeña empresa mediante Python.

---

## Objetivos

- Gestionar tareas utilizando Jira.
- Aplicar control de versiones mediante Git y GitHub.
- Implementar trazabilidad entre tareas e historial de commits.
- Analizar datos de ventas utilizando Python.
- Generar indicadores y gráficos de análisis.
- Aplicar buenas prácticas de organización y documentación.

---

## Estructura del Proyecto

- `datos/` → Archivos CSV utilizados para el análisis.
- `scripts/` → Scripts Python del proyecto.
- `resultados/` → Gráficos y resultados generados.

---

## Tecnologías Utilizadas

- Python
- Google Colab
- Git
- GitHub
- Jira Software

---

## Funcionalidades Implementadas

- Lectura de archivos CSV
- Cálculo de ventas totales
- Identificación de productos más vendidos
- Análisis de ventas mensuales
- Generación de gráficos

---

## Organización del Trabajo

El proyecto fue organizado mediante un tablero Kanban en Jira utilizando Issues para la asignación y seguimiento de tareas.

Cada commit realizado en GitHub mantiene trazabilidad con Jira mediante el uso de identificadores de tareas.

---

## Dataset Utilizado

El proyecto utiliza un dataset de ventas simulado almacenado en el archivo:

```text
datos/ventas.csv

El dataset contiene información relacionada con:

fecha de venta
producto vendido
cantidad
precio unitario

Estos datos fueron utilizados para realizar cálculos de ventas totales, análisis mensuales y generación de gráficos.

Ejecución del Proyecto

Para ejecutar el análisis de datos:

python scripts/analisis_datos.py

El script generará:

indicadores de ventas
análisis mensual
gráfico de ventas por producto

Los resultados se almacenan automáticamente en la carpeta:

resultados/
